# Devocional — App de Fé com Tecnologia

Página oficial de apresentação do aplicativo Devocional, uma plataforma dedicada à meditação espiritual, leitura bíblica e conexão comunitária. Este é o portal para testadores selecionados participarem da fase de teste fechado.

## About the Project

Devocional nasce da convicção de que fé e tecnologia podem se encontrar de forma significativa. Oferecemos:

- Devocionais diários preparados por líderes espirituais
- Material de estudo bíblico aprofundado
- Comunidade de crentes conectada globalmente
- Interface limpa e intuitiva
- Segurança e privacidade em primeiro lugar

## File Structure

- `index.html` — página principal
- `styles.css` — design profissional dark theme
- `script.js` — funcionalidades dinâmicas
- `assets/` — pasta para imagens, screenshots e ícones

## Publicação no GitHub Pages

1. Crie um repositório `devocional-landing` no GitHub.
2. Clone este projeto no repositório.
3. Faça commit e push para a branch `main`.
4. Ative GitHub Pages nas configurações do repositório, selecionando branch `main`.
5. A página estará disponível em `https://seu-usuario.github.io/devocional-landing`.

## Customização

- Substitua os arquivos SVG em `assets/` por imagens reais do app.
- Atualize os dados de contato em `index.html`.
- Modifique as cores em `styles.css` se desejar.
